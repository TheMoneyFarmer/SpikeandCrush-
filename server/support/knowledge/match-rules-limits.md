# Starting capital, lot limits and open positions

Every match uses the same core rules:

- Starting capital: $10,000 (virtual, resets every match)
- Maximum size per trade: 10 lots (some instruments have a lower maximum of their own; the lower one applies)
- Maximum open positions at once: 10

Long-form competitions use the same starting capital, lot limit and position limit.
